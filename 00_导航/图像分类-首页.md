# 图像分类

本仓库位于 `LOCAL_VAULT`，用于保存本项目所有 Markdown 资料及其关联知识。PDF 通过 Zotero 插件归入项目专属资料库的“图像分类”集合，受管原件保存在本文件夹内 `Zotero\data`，另在 `PDF原文` 平铺保存按论文题目命名的独立副本。科研 skills 单独保留在外层 `LOCAL_VAULT\科研skills`。

## 从这里开始

- **PDF 副本与目录：[整理与PDF副本说明](../PUBLICATION_SCOPE.md)**。3 个不同版本的原文直接放在 `PDF原文`，没有逐篇子文件夹。

- **期刊全文：[EVP TPAMI逐段中英对照](../PUBLICATION_SCOPE.md)**（用户提供正式PDF，16页）。附中文术语与例题。

- **零基础教材：[从零读懂EVP·完整教材版](../04_%E6%95%99%E5%AD%A6/EVP%E9%9B%B6%E5%9F%BA%E7%A1%80%E6%95%99%E6%9D%90/EVP%E9%9B%B6%E5%9F%BA%E7%A1%80%E5%AD%A6%E4%B9%A0%E6%89%8B%E5%86%8C_%E6%95%99%E6%9D%90%E7%89%88.md)**。12章从数学与像素开始，含25道完整例题、37道解答练习；分章阅读见 [教材首页](../04_%E6%95%99%E5%AD%A6/EVP%E9%9B%B6%E5%9F%BA%E7%A1%80%E6%95%99%E6%9D%90/00_%E6%95%99%E6%9D%90%E9%A6%96%E9%A1%B5%E4%B8%8E%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF.md)。
- [论文索引](%E8%AE%BA%E6%96%87%E7%B4%A2%E5%BC%95.md)：逐篇记录检索、入库和阅读状态。
- [术语索引](../02_%E6%9C%AF%E8%AF%AD/%E6%9C%AF%E8%AF%AD%E7%B4%A2%E5%BC%95.md)：复用规范术语，用双向链接串联论文和方法。
- [实验索引](../03_%E5%AE%9E%E9%AA%8C/%E5%AE%9E%E9%AA%8C%E7%B4%A2%E5%BC%95.md)：记录可复现的训练、评估和失败结果。
- [教学索引](../04_%E6%95%99%E5%AD%A6/%E6%95%99%E5%AD%A6%E7%B4%A2%E5%BC%95.md)：进入教学模式后保存每章精要与全部例题。
- [交接索引](../PUBLICATION_SCOPE.md)：额度中止前或跨会话继续时的状态入口。
- [项目默认规则](../PUBLICATION_SCOPE.md)、[科研技能来源清单](../PUBLICATION_SCOPE.md)。

## 资料处理顺序

检索并核对来源 → 项目内获取 PDF → Zotero 插件入库并读回核对 → 建立 [论文笔记](../PUBLICATION_SCOPE.md) → 链接 [术语](../02_%E6%9C%AF%E8%AF%AD/%E6%9C%AF%E8%AF%AD%E7%B4%A2%E5%BC%95.md)、相关论文和 [实验](../03_%E5%AE%9E%E9%AA%8C/%E5%AE%9E%E9%AA%8C%E7%B4%A2%E5%BC%95.md)。

已整理18个入门术语节点，见 [术语索引](../02_%E6%9C%AF%E8%AF%AD/%E6%9C%AF%E8%AF%AD%E7%B4%A2%E5%BC%95.md)。基础定义已补充，不代表已经完成文献综述或实验复现。

应用连接、技能安装和附件入库状态见 [使用与验收](../PUBLICATION_SCOPE.md)；包含可直接执行的启动与插件入口。
