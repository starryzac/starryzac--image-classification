# 术语索引与易混概念

这份索引用于查找已经在正文讲过的词。第一次学习时，应回到对应章节读定义、计算过程和例题；仅记住一句定义，通常还不足以使用公式。括号中的英文或缩写帮助你对应论文和代码，不要求先背英文。本页复用已有规范术语节点，避免让同一个概念在 Obsidian 图中变成多个重名节点。

## 一、数学语言：回到第1章

系统说明与算例：[01_读公式之前的数学语言](01_%E8%AF%BB%E5%85%AC%E5%BC%8F%E4%B9%8B%E5%89%8D%E7%9A%84%E6%95%B0%E5%AD%A6%E8%AF%AD%E8%A8%80.md)。

| 术语 | 本书中的明确含义 | 首先检查什么 |
|---|---|---|
| 变量 / 常量 | 变量是讨论中允许变化的量；常量是在当前讨论条件下固定的量 | 同一个数在不同问题里角色可以改变 |
| 函数（function） | 一条使每个允许输入对应一个确定输出的规则 | 输入的允许范围，以及输出是什么 |
| 自变量 / 参数 | 自变量是当前研究的输入；参数控制函数的具体规则 | 训练时也可以把损失看作参数的函数 |
| 下标（index） | 指定某个数在一组数中的位置 | 本书数组位置从0开始；不是所有下标都代表位置 |
| 求和（summation） | 按给定范围把指定项相加 | 首项、末项、总项数是否一致 |
| 算术平均（mean） | 总和除以项数 | 平均哪些数，是否包含所有项 |
| 加权和（weighted sum） | 各数乘各自权重后相加 | 权重可以为负，未必和为1 |
| 加权平均（weighted average） | 在本书初等例子中，用非负、和为1的权重组合数值 | 权重为零意味着该项不贡献；不是删掉原数据 |
| 标量（scalar） | 一个数 | 并不等于它只能取整数 |
| 向量（vector） | 按顺序排列的一组数 | 本次约定是行还是列，包含几个分量 |
| 矩阵（matrix） | 按行列排列的数表 | 行数与列数不能互换 |
| 形状（shape） | 每一轴的长度，按轴顺序列出 | “2×3”和“3×2”含6个数，但组织方式不同 |
| 转置（transpose） | 把矩阵的行和列互换 | 元素位置从行r列c变成行c列r |
| 逐元素乘法 | 对应位置的数相乘 | 对应关系必须清楚；不等于矩阵乘法 |
| 点积（dot product） | 两个等长数列对应相乘再求和 | 得到一个数，不是一列数 |
| 矩阵乘法 | 左边每一行与右边每一列做点积 | 左边列数必须等于右边行数 |
| 指数 / 自然对数 | 指数描述以某个底重复相乘的延伸；自然对数回答e的几次方等于给定正数 | ln的实数输入必须大于0；ln不是乘法 |

## 二、图片表示：回到第2章

系统说明：[02_一张图片如何变成数字](02_%E4%B8%80%E5%BC%A0%E5%9B%BE%E7%89%87%E5%A6%82%E4%BD%95%E5%8F%98%E6%88%90%E6%95%B0%E5%AD%97.md)。规范节点：[图像张量](../../02_%E6%9C%AF%E8%AF%AD/%E5%9B%BE%E5%83%8F%E5%BC%A0%E9%87%8F.md)。

| 术语 | 本书中的明确含义 | 容易混淆之处 |
|---|---|---|
| 像素（pixel） | 离散图片中一个空间采样位置；该位置可带有多个通道值 | “位置”和“该位置的数值”要分开说 |
| 灰度值（grayscale value） | 单通道图在某个位置记录的强度数值 | 255是特定8位表示的最大值，不是所有格式的上限 |
| RGB通道 | 同一位置上按红、绿、蓝排列的三个数值分量 | 三个通道不是三个物体，也不是三张不同样本 |
| 位（bit） / 字节（byte） | 一位表示二选一的信息；通常8位构成一个字节 | 位数与像素个数不是同一个量 |
| 数据类型（dtype） | 规定数如何表示及可用范围，例如无符号8位整数、32位浮点数 | 相同元素个数，不同类型占用空间不同 |
| 张量（tensor） | 在本书计算语境中，按一个或多个轴排列的数值数组 | “几阶数组”与“某轴有几个元素”应分清 |
| 轴（axis） | 数组的一个索引方向，例如批次、通道、行、列 | 交换轴需要移动对应元素，不能只改形状标签 |
| 批次（batch） | 一次共同参与计算的一组样本 | 批次轴不属于单张图片的空间位置 |
| 归一化（normalization） | 一类按指定规则调整数值范围或统计量的操作 | 必须说具体公式；除以255与LayerNorm不是同一规则 |
| 标签（label） | 任务提供的目标答案 | 标签不是模型自己预测出的数 |
| 掩码（mask） | 用一个与位置相对应的数组表示区域选择或权重 | 真值、预测硬掩码、软权重掩码不是同一个东西 |
| 预测分数（score） | 模型输出的、用于判断某类的数 | 0.9不是“这张图90%的像素正确” |
| 阈值（threshold） | 把连续分数分成不同判断时使用的界线 | 本书默认分数大于或等于0.5判为前景，必须保留等号约定 |

## 三、模型和学习：回到第3–4章

系统说明：[03_从计算规则到神经网络](03_%E4%BB%8E%E8%AE%A1%E7%AE%97%E8%A7%84%E5%88%99%E5%88%B0%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C.md)、[04_模型怎样从错误中学习](04_%E6%A8%A1%E5%9E%8B%E6%80%8E%E6%A0%B7%E4%BB%8E%E9%94%99%E8%AF%AF%E4%B8%AD%E5%AD%A6%E4%B9%A0.md)。规范节点：[监督学习](../../02_%E6%9C%AF%E8%AF%AD/%E7%9B%91%E7%9D%A3%E5%AD%A6%E4%B9%A0.md)、[梯度与反向传播](../../02_%E6%9C%AF%E8%AF%AD/%E6%A2%AF%E5%BA%A6%E4%B8%8E%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD.md)、[二元交叉熵](../../02_%E6%9C%AF%E8%AF%AD/%E4%BA%8C%E5%85%83%E4%BA%A4%E5%8F%89%E7%86%B5.md)、[训练验证测试划分](../../02_%E6%9C%AF%E8%AF%AD/%E8%AE%AD%E7%BB%83%E9%AA%8C%E8%AF%81%E6%B5%8B%E8%AF%95%E5%88%92%E5%88%86.md)。

| 术语 | 具体含义 | 区别或边界 |
|---|---|---|
| 模型（model） | 用输入和参数计算输出的一组规则 | 架构规定计算方式，参数规定当前的具体数值 |
| 权重（weight） / 偏置（bias） | 权重缩放并组合输入；偏置是额外加上的常数项 | 这里的“常数”指一次前向时固定，训练时可以更新 |
| 特征（feature） | 供后续判断使用的数值表示 | 一个特征分量不一定对应一个可以命名的物体 |
| 层（layer） | 网络中一段有明确输入输出的计算 | 一个软件模块可能包含多个数学运算 |
| 仿射变换（affine transformation） | 矩阵乘法后再加偏置，如XW+b | 软件的Linear层常包含偏置，因此不一定是严格线性映射 |
| 激活函数（activation） | 通常逐元素作用的非线性函数 | ReLU与Sigmoid的输出范围、用途不同 |
| ReLU | 把负输入变为0，非负输入保持原值的函数 | 它不把所有输入限制在0到1之间 |
| Sigmoid | 把任意有限实数平滑映射到0与1之间的函数 | 它让分数有界，但不自动保证预测可靠 |
| logit | 本书二元问题中，送入Sigmoid之前的实数分数z | 不是经过阈值后的0或1 |
| 多层感知机（MLP） | 由可学习的仿射变换和非线性等步骤组成的网络模块 | 具体几层、每层多宽要看定义，不能由名字猜测 |
| 前向计算（forward） | 从输入和参数按依赖顺序计算输出 | 推理时需要它；训练时还会接着算损失 |
| 损失函数（loss） | 把当前预测与目标差别量化为训练目标的规则 | 某种损失下降，不保证所有测试指标提高 |
| 二元交叉熵（BCE） | 对二元标签，用对数惩罚错误方向上的分数 | 先核实输入是概率还是logit，防止重复Sigmoid |
| 差商 | 函数改变量除以非零的输入改变量 | 是有限区间的平均变化率 |
| 导数（derivative） | 在某点，差商随非零改变量趋近零而趋近的变化率 | 不是把差商的分母直接设为0 |
| 偏导数（partial derivative） | 暂时固定其他变量，仅改变某一变量得到的导数 | 要先说清固定谁、改变谁 |
| 梯度（gradient） | 按约定顺序收集的各参数偏导数 | 它描述当前位置变化率，不是更新后的参数 |
| 链式法则（chain rule） | 沿复合计算路径组合局部导数的规则 | 多条依赖路径还要把贡献相加 |
| 反向传播（backpropagation） | 沿计算依赖高效应用链式法则求梯度的方法 | 求梯度与用梯度更新参数是两个步骤 |
| 学习率（learning rate） | 在参数更新规则中缩放改变量的正数 | 大一些未必学得好，可能一步跨过并增大损失 |
| 超参数（hyperparameter） | 通常由训练方案设定的量，如学习率、批次大小 | 与通过损失更新的模型参数区分 |
| 训练轮次（epoch） | 按既定采样规则完整遍历训练集一次 | 一轮通常含多个批次与多次参数更新 |
| 过拟合（overfitting） | 对训练材料拟合得好，却不能同样适用于新的相关材料 | 仅报告训练损失不足以排除它 |
| 数据泄漏（data leakage） | 本应独立的评估过程受到训练或选择中不应使用的信息影响 | 相似图像跨集合、用测试结果调参都需检查 |

## 四、分割系统和评价：回到第5–6章

系统说明：[05_从整图判断到逐像素分割](05_%E4%BB%8E%E6%95%B4%E5%9B%BE%E5%88%A4%E6%96%AD%E5%88%B0%E9%80%90%E5%83%8F%E7%B4%A0%E5%88%86%E5%89%B2.md)、[06_怎样衡量分割结果](06_%E6%80%8E%E6%A0%B7%E8%A1%A1%E9%87%8F%E5%88%86%E5%89%B2%E7%BB%93%E6%9E%9C.md)。规范节点：[图像分类](../../02_%E6%9C%AF%E8%AF%AD/%E5%9B%BE%E5%83%8F%E5%88%86%E7%B1%BB.md)、[前景分割](../../02_%E6%9C%AF%E8%AF%AD/%E5%89%8D%E6%99%AF%E5%88%86%E5%89%B2.md)、[卷积神经网络](../../02_%E6%9C%AF%E8%AF%AD/%E5%8D%B7%E7%A7%AF%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C.md)、[分割评价指标](../../02_%E6%9C%AF%E8%AF%AD/%E5%88%86%E5%89%B2%E8%AF%84%E4%BB%B7%E6%8C%87%E6%A0%87.md)。

| 术语 | 具体含义 | 使用前必须确认 |
|---|---|---|
| 图像分类 | 给整张图判断类别或属性 | 单标签和多标签设定不同 |
| 二元前景分割 | 给每个位置判断是否属于任务指定区域 | 前景由任务定义，不等于亮、近或完整物体 |
| 卷积核（kernel） | 在局部窗口中使用的一组权重 | 深度学习常用不翻转核的互相关约定 |
| 特征图（feature map） | 保留空间排列的特征数表 | 它通常还不是最终预测标签 |
| 步幅（stride） | 相邻窗口起点之间的间隔 | 决定采样位置，不是把输出乘这个数 |
| 填充（padding） | 在边界外按规则补入数值 | 零填充不是额外观测到的像素 |
| 感受野（receptive field） | 某个输出可能依赖的输入区域 | 多层叠加后的范围与单层核大小不同 |
| 下采样 / 上采样 | 分别缩小 / 扩大空间网格 | 尺寸恢复不等于已丢失信息恢复 |
| 池化（pooling） | 按规则把一个区域概括为较少的数 | 平均池化与最大池化结果不同 |
| 编码器 / 解码器 | 分别形成内部表示 / 由表示生成任务输出的功能部分 | 不限定必须由卷积构成 |
| 跳跃连接（skip connection） | 将较早表示送往较后计算的连接 | 相加和拼接的形状要求不同 |
| TP / FP / FN / TN | 真前景判前景、真背景误判前景、真前景漏判背景、真背景判背景四种计数 | 本书以“前景”为正类，先固定阈值再计数 |
| 精确率（precision） | 判为前景的像素中，确实为前景的比例 | 与整体准确率不同，分母可能为0 |
| 召回率（recall） | 真正前景像素中，被找回的比例 | 不单独惩罚把很多背景也判前景 |
| IoU / Dice | 分别按交并比、两倍交集除以两个集合大小之和衡量区域重合 | 给定同一对硬掩码时有固定联系，跨图平均后需谨慎 |
| MAE | 逐像素预测分数与标签的绝对差，再取平均 | 软分数误差不等于阈值后错分比例 |
| F-measure | 按指定权衡组合精确率与召回率的一类分数 | 注明beta参数、阈值集合，以及在图像/阈值维度上先平均还是先取最大；顺序不能随意交换 |
| BER | 前景漏检率和背景误报率的算术平均 | 论文常按百分数报告，不能与0到1的小数直接比较 |
| ROC / AUC | ROC描述阈值变化时真假阳性率的关系；AUC概括曲线下面积 | 排序好不等于某个固定阈值的硬掩码最好 |
| S-measure / E-measure / weighted F | 分别引入结构、对齐或误差空间权重的特定指标 | 必须使用各自定义和实现，不能都简写成普通混淆计数公式 |

## 五、Transformer与参数适配：回到第7–8章

系统说明：[07_图像块与Transformer](07_%E5%9B%BE%E5%83%8F%E5%9D%97%E4%B8%8ETransformer.md)、[08_预训练冻结与视觉提示](08_%E9%A2%84%E8%AE%AD%E7%BB%83%E5%86%BB%E7%BB%93%E4%B8%8E%E8%A7%86%E8%A7%89%E6%8F%90%E7%A4%BA.md)。规范节点：[图像块与嵌入](../../02_%E6%9C%AF%E8%AF%AD/%E5%9B%BE%E5%83%8F%E5%9D%97%E4%B8%8E%E5%B5%8C%E5%85%A5.md)、[注意力机制](../../02_%E6%9C%AF%E8%AF%AD/%E6%B3%A8%E6%84%8F%E5%8A%9B%E6%9C%BA%E5%88%B6.md)、[视觉Transformer](../../02_%E6%9C%AF%E8%AF%AD/%E8%A7%86%E8%A7%89Transformer.md)、[冻结与微调](../../02_%E6%9C%AF%E8%AF%AD/%E5%86%BB%E7%BB%93%E4%B8%8E%E5%BE%AE%E8%B0%83.md)、[视觉提示](../../02_%E6%9C%AF%E8%AF%AD/%E8%A7%86%E8%A7%89%E6%8F%90%E7%A4%BA.md)、[适配器与参数高效微调](../../02_%E6%9C%AF%E8%AF%AD/%E9%80%82%E9%85%8D%E5%99%A8%E4%B8%8E%E5%8F%82%E6%95%B0%E9%AB%98%E6%95%88%E5%BE%AE%E8%B0%83.md)。

| 术语 | 具体含义 | 不能由名字推断的内容 |
|---|---|---|
| 图像块（patch） | 按既定空间范围取出的图片小块 | 大小、是否重叠、边界处理要看实际定义 |
| 词元（token，亦称令牌） | 被模型作为一个处理单位的向量表示 | 图像词元不等于自然语言单词 |
| 嵌入（embedding） | 将原输入转成后续模型使用的向量表示的计算或结果 | 不是把图片保存到文件，也不必只有查表操作 |
| 位置编码 | 向计算提供词元位置信息的表示或规则 | 具体是相加、相对偏置还是别的方式须看模型 |
| Q / K / V | 查询、键和值，是由输入经过指定映射得到的三组向量 | 它们是数值角色，不是模型有了人类提问意图 |
| softmax | 将一组实数先取指数，再除以指数和，得到和为1的正权重 | 必须指定在哪一轴或哪一组数上归一化 |
| 注意力（attention） | 根据查询与键计算权重，再组合值向量的运算 | 权重高不自动等于因果解释或物体定位 |
| 多头注意力 | 用多组映射分别计算注意力，再合并输出 | 多个头不保证分别学到人为指定的概念 |
| LayerNorm | 在每个指定单位内部，按所选特征轴做均值方差标准化并可再学习缩放和平移 | 与除以255、按批次统计的操作不同 |
| GELU | 一种平滑的逐元素非线性激活，本书第7章说明其数学定义与常用行为 | 不能把它当成与ReLU完全相同 |
| 预训练（pretraining） | 在当前任务适配之前，通过其他训练阶段获得参数 | 训练数据、目标与权重版本都需要说明 |
| 微调（fine-tuning） | 从已有参数出发，在当前任务上继续调整指定参数 | 不一定调整全部参数 |
| 冻结（freeze） | 训练中不更新指定参数 | 冻结部分仍参与前向，必要时仍需向前端传递梯度 |
| 适配器（adapter） | 插入或附加到已有网络、用于学习任务调整的小模块 | 插入位置、瓶颈大小、激活与残差方式各不相同 |
| LoRA | 以两个较小矩阵的乘积表示某种权重增量的适配方式 | 不是所有低参数方法都叫LoRA |
| 视觉提示（visual prompt） | 以输入或特征等形式引导已有视觉模型适应任务的表示 | 未必是人写的自然语言，也未必与图片无关 |
| 可训练参数量 | 在当前训练设定中允许更新的参数个数 | 不等于总参数量、运行次数、显存或耗时 |

## 六、频率和EVP：回到第9–12章

系统说明：[09_从周期变化到傅里叶变换](09_%E4%BB%8E%E5%91%A8%E6%9C%9F%E5%8F%98%E5%8C%96%E5%88%B0%E5%82%85%E9%87%8C%E5%8F%B6%E5%8F%98%E6%8D%A2.md)、[10_EVPv1逐步拆解](10_EVPv1%E9%80%90%E6%AD%A5%E6%8B%86%E8%A7%A3.md)、[11_EVPv2逐步拆解](11_EVPv2%E9%80%90%E6%AD%A5%E6%8B%86%E8%A7%A3.md)、[12_读懂实验与走向代码](12_%E8%AF%BB%E6%87%82%E5%AE%9E%E9%AA%8C%E4%B8%8E%E8%B5%B0%E5%90%91%E4%BB%A3%E7%A0%81.md)。规范节点：[傅里叶变换与高频](../../02_%E6%9C%AF%E8%AF%AD/%E5%82%85%E9%87%8C%E5%8F%B6%E5%8F%98%E6%8D%A2%E4%B8%8E%E9%AB%98%E9%A2%91.md)、[傅里叶多层感知机](../../02_%E6%9C%AF%E8%AF%AD/%E5%82%85%E9%87%8C%E5%8F%B6%E5%A4%9A%E5%B1%82%E6%84%9F%E7%9F%A5%E6%9C%BA.md)、[自适应提示生成器](../../02_%E6%9C%AF%E8%AF%AD/%E8%87%AA%E9%80%82%E5%BA%94%E6%8F%90%E7%A4%BA%E7%94%9F%E6%88%90%E5%99%A8.md)。

| 术语 | 具体含义 | 常见误解 |
|---|---|---|
| 周期（period） | 一种变化重复一次所需的间隔 | 图像中可以是空间距离，不一定是时间 |
| 频率（frequency） | 在指定单位间隔内变化重复的次数 | 高频是快变化，不等于高亮度 |
| 振幅 / 相位 | 分别描述变化的大小 / 在周期中的起始位置或偏移 | 幅度相同不保证波形位置相同 |
| 复数（complex number） | 由实部与虚部组成的数，可写为a+jb，其中j²=−1 | 两个分量不等于图像有两个颜色通道 |
| 共轭（conjugate） | a+jb的共轭是a−jb | 共轭不是简单取负整个复数 |
| DFT | 离散傅里叶变换：按固定复数权重，把有限序列改写为频率系数 | 必须交代长度、方向符号、归一化与变换轴 |
| 逆DFT / IFFT | 逆DFT是由频率系数重建序列的数学变换；IFFT是它的快速算法或接口 | 删改频率之后，重建的是改变后的序列 |
| FFT | 高效计算DFT的一类算法 | 不代表与DFT不同的分析目标 |
| fftshift | 为显示或处理方便而重新排列频率位置的操作 | 本身不做傅里叶变换，也不删除频率 |
| 高频成分 | 对应较快空间变化的频率部分 | 边缘、纹理、噪声都可能贡献，不专属于前景 |
| 频率掩码 | 给不同频率位置乘以选择值或权重的数组 | 硬0/1与连续软权重不同，还要检查共轭对称性 |
| 显式视觉提示（EVP） | 本论文中从输入有关的信息构造提示，以适配冻结主干的方法体系 | 期刊的v1/v2具体计算不能由通用“提示”二字推断 |
| 提示生成器（Prompter） | EVPv1中融合图像块嵌入支路与高频分量支路的特征，生成逐层提示的模块 | 其输入、共享参数和每层参数要分开数 |
| 傅里叶多层感知机（Fourier MLP） | EVPv2中对图像嵌入作FFT，学习实部/虚部软掩码并加权，再经IFFT得到特征的模块 | 具体变换轴及复数实现必须以代码为证，不能由名字补全 |
| 自适应提示生成器（Adaptive Prompter） | EVPv2中根据输入特征自适应形成提示的模块 | 自适应输出变化不等于每张图都重新训练参数 |
| 基线（baseline） | 在明确设置下用于比较的参照方法 | 名字相同但主干、分辨率不同，比较也可能不公平 |
| 消融实验（ablation） | 有控制地移除或改变部件，观察指标如何变化的比较 | 一次差异不自动证明在所有任务中有同样因果效应 |
| 复现（reproduction） | 按明确数据、代码、环境和设置实际运行并核验结果的工作 | 阅读代码、翻译论文、算玩具例题都不等于已复现 |

## 七、九组必须用完整句子说清的区别

1. **像素值、标签和预测分数。** 像素值描述输入图片；标签描述任务答案；预测分数描述模型当前判断。三者数值恰好一样时，角色仍不同。
2. **形状、轴数和元素总数。** 形状为2×3×4的数组有3个轴，24个元素。把它叫“24维图像”容易混淆，应该具体说明。
3. **输入、参数和超参数。** 输入随样本改变；参数通常由训练更新；学习率等超参数规定训练方案。冻结参数后，新输入仍能产生新输出。
4. **损失、梯度和更新。** 损失量化当前差别；梯度计算局部敏感方向；更新规则据此改参数。这三步有依赖顺序。
5. **概率形式与可靠概率。** Sigmoid使结果处在0到1之间，但分数0.9是否对应约90%的真实发生比例，还需用数据检查。
6. **参数共享与输出相同。** 同一个卷积核或提示生成器能在不同位置、不同图片上得到不同输出，因为输入不同。共享的是规则中的数。
7. **冻结与切断计算依赖。** 不更新某层参数，不代表可以删掉这一层。如果前面的可训练部分影响最终损失，求梯度仍要沿必要路径通过冻结层。
8. **低频/高频与语义。** 频率描述变化快慢，前景描述任务想找什么。它们可能相关，不能直接画等号。
9. **少参数与省资源。** 可训练参数少通常减少需更新的数，但主干前向、激活保存、额外模块和输入尺寸仍影响时间与内存。要分别测量再作结论。
