# 从零读懂EVP：教材首页与学习路线

这套教材面向尚未学过线性代数、微积分、概率、神经网络和Python的计算机专业本科生。只默认你会四则运算、分数和简单代数代入。教材的目标是让你能够逐步读懂 **2025年在线发表的TPAMI论文《Explicit Visual Prompting for Universal Foreground Segmentations》**，说清它做什么、怎样计算、哪些参数在学习、实验支持哪些结论。

这次重写把原来压在几个段落里的前置知识拆开：数学符号先于模型公式，模型计算先于参数学习，分割任务先于分割指标，矩阵乘法先于注意力，周期与复数先于傅里叶变换。论文方法放在这些基础之后。每一章在正文首次使用新术语时解释它，术语表用来复习，不能代替正文推导。

## 怎样使用这本书

有两种阅读入口：[连续阅读整本教材](EVP%E9%9B%B6%E5%9F%BA%E7%A1%80%E5%AD%A6%E4%B9%A0%E6%89%8B%E5%86%8C_%E6%95%99%E6%9D%90%E7%89%88.md)，或按下表逐章阅读。分章版便于在Obsidian中做批注和查看反向链接；整合版由相同章节生成，内容来源一致。

每章先读“为什么需要”，再跟着例题自己写一遍中间量。练习先遮住答案，完成后对照步骤，而不只是对最终数字。遇到不理解的符号，回到它首次定义的章节；不必靠猜测继续往下读。没有规定必须几分钟读完一章，以能够解释并独立计算为过关标准。

本书把三类内容明确区分：**基础定义和自拟例题**用于建立概念；**论文原式及实验数据**标注公式或表格位置；**本机复现结果**目前不存在，阅读教材和核算例题不能代替模型训练。

## 统一记号：第一次遇到时不要自行猜

| 记号 | 本书默认含义 | 提醒 |
|---|---|---|
| r、c | 图像的行号、列号 | 从0编号；在论文方法中r还可作降维因子，届时会重新定义 |
| H、W、C | 图像高、宽、通道数 | 大写W在模型公式也可表示权重矩阵，必须看局部定义 |
| B、N、d | 批大小、样本/词元数量、向量宽度 | 不应把“样本个数”和“一个样本有几个数”互换 |
| y、p、z | 真值标签、预测分数、Sigmoid之前的实数 | 三者来源不同，形状相同不等于含义相同 |
| ≥0.5 | 本书默认前景判定规则 | 若例题换阈值，会明确说明；恰好等于阈值也算前景 |
| ln、e | 自然对数、自然常数 | 第1章给定义，不要求先学极限 |
| j | 复数的虚数单位，j²=−1 | 第9章定义；原论文中的i常表示层序号 |
| ×、⊙ | 一般乘法/形状中的长度关系、明确的逐元素乘法 | 真正矩阵运算必须同时检查形状 |

所有符号都以所在公式旁的定义为准。“同一个字母始终只能表示同一个对象”在论文中并不成立，因此教材会说明何时改变含义。

## 读前自测与答案

1. **计算 $2(3+1)$。**先括号得4，再乘2得8。若这一步不熟练，先练代入和括号顺序。
2. **三个数2、4、6的平均值是多少？**先求和12，再除以数量3，得到4。
3. **两行三列共有几个位置？**$2\times3=6$，不是 $2+3=5$。
4. **看到一个0.9，能否判断它是亮度、概率还是参数？**不能；必须知道它来自哪里、怎样计算。
5. **读完一张实验表，能否直接声称本机复现成功？**不能；读取作者结果与在本机运行并记录证据是两件事。

前三题用于确认起点，后两题是贯穿全书的阅读习惯。若基础已经较熟悉，可以直接做每章习题检查是否具备前置知识，但不要跳过方法章节中的版本和符号说明。
